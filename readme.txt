A lightweight SEO plugin with the essential on-page SEO features.

== Description ==

Easy SEO is a lightweight WordPress SEO plugin inspired by the proven architecture of popular SEO plugins. It brings you the essential on-page SEO features without the bloat:

* SEO titles and meta descriptions for posts, pages, products and terms
* Focus keyword support
* Custom canonical URLs
* Robots meta (noindex / nofollow) per post
* Open Graph tags for Facebook and other social networks
* Twitter Card tags
* JSON-LD structured data (WebSite and Article)
* XML sitemap with sitemap index
* Search engine pinging on new published content
* Google and Bing site verification
* SEO columns in the posts list

== Installation ==

1. Upload the `easy-seo` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to the 'Easy SEO' menu to configure the settings.

== Frequently Asked Questions ==

= Where is the sitemap? =

The XML sitemap is available at `https://yoursite.com/sitemap.xml`.
